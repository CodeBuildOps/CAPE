CAPE is a Desktop/Web-based application that helps the client:

Edit,
Manage,
Analyze,
Track the record, and
Give the recommendation products which are high or low
From both checkout and abandoned sectors.

What features this application should have?
Login page (also have to Forget Password)

Registration page (Having upload image and email authentication)

Entry page having:

Abandoned Page
Purchased Page
Dashboard having features:

Display all Purchased session
Display all Abandoned session
Should have new/delete/update features
Storing/Access data :

Database (Remotely, Safe & Secure)
Google Sheets API
Recommendation system and analyzing tools for the products according to the Purchased and Abandoned Entries

Chatbot integrated into Web and from Desk, which will redirect to Web

Should have features like Email sending, Personalize register person, Security log in with email enabled OTP
